# wtlfo

LFO visualizer and learning tool for Elektron Digitakt II.

**Try it on the web: [wtlfo.expo.app](https://wtlfo.expo.app/)**

**iOS beta: [join via TestFlight](https://testflight.apple.com/join/SzTrg99R)**

Supports iOS and web (Android not yet supported).

## Requirements

- For iOS: Xcode ([setup guide](https://docs.expo.dev/guides/local-app-development/#ios-development))

## Run

```bash
bun install

# iOS
bun expo run:ios

# Web
bun expo start --web
```
